# IYC 2026 训练营资料馆

## 本地预览

在资料馆文件夹的终端运行：

```powershell
python server.py
```

保持终端运行，在浏览器打开 `http://127.0.0.1:8765/`。如果 8765 端口已被旧进程占用，可运行：

```powershell
$env:IYC_PORT='8766'; python server.py
```

再打开 `http://127.0.0.1:8766/`。

## 页面编辑

点击右上角“编辑页面”后：

- 拖动卡片右上角的 `↕` 调整同一组卡片的顺序。
- 点击卡片右上角的 `×`，只会从当前浏览器的页面布局中隐藏卡片，不会删除照片或资料原件。
- 点击“完成编辑”退出编辑模式；再次打开页面会保留本浏览器的布局。
- 点击“恢复默认”清除已保存的隐藏和排序设置。

## 预览

照片和 PDF 的预览缩略图由服务器按需生成，并保存在 `.preview-cache`。PPTX 优先使用配套 PDF 的第一页作为封面；下载仍会下载原始 PPTX。照片预览是压缩缩略图，原图下载链接不会经过缩放或转码。
